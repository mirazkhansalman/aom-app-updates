# AOM (Application for Office Management) - Public Release & Update Channel

Official public distribution and silent auto-update repository for **AOM (Application for Office Management)** desktop applications.

## Latest Version
- **Version:** `v1.4.1` (Build 77 - `b625ea2`)
- **Release Date:** November 19, 2026
- **Architecture:** Electron Multi-Platform Desktop (Windows / macOS)
- **Status:** Public In-App Auto-Update Channel (Active)

## How It Works
AOM Desktop clients automatically check `version.json` in this repository upon launch. When a newer version is released, clients receive an in-app update notification and can update seamlessly in a single click with SHA-256 cryptographic verification.
